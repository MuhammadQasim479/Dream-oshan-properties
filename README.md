# Awtad Development — Website (UAE / Dubai)

Stack: React 18, Vite, Tailwind CSS 3, Framer Motion, react-icons, react-router-dom.

    npm install
    npm run dev      # development
    npm run build    # production build in /dist

## Editing content
ALL text, numbers, links and image URLs live in one file: `src/data/content.js`
(company info, navbar, footer, home sections, projects + detail pages, team, contact, FAQ, testimonials).
Colors and fonts are in `tailwind.config.js`.
Items marked `TODO` (phone, email, address, project site link, FAQs, bios) are placeholders to replace.
